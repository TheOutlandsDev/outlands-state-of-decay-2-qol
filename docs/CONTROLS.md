# Controls and mode notes

| Function | Control |
| --- | --- |
| First / third person | Shift + F3 after loading into the world |
| Wider / narrower first-person FOV | Shift + Page Up / Page Down |
| Reset first-person FOV | Shift + End |
| Enclave Editor | F3 |
| Clock menu | F5 |
| Follower health/stamina display | Alt + Num2 |

The camera starts in third person and may need toggling again after switching survivors. FOV resets between sessions. Passenger camera positioning is not tuned; first-person co-op client behavior is untested. See the [first-person author's notes](https://www.nexusmods.com/stateofdecay2/mods/1642).

## Heartland community additions

Heartland's regular recruits belong to its story. Missing ordinary Campaign recruitment dialogue does not by itself mean a mod is broken. Exploration and missions unlock normal recruitment; see the [official Heartland tips](https://support.stateofdecay.com/hc/en-us/article_attachments/360030480311).

Enclave Editor adds a separate manual route: F3, **EME Player Enclave Data**, **Add Member**. The **GZ Recruit** preset creates an ordinary survivor through the **Try add** controls. It is not a new conversation option on every NPC. Adding a person is a persistent game change once saved.

Prefer ordinary additions over duplicating named story characters. Force-adding a unique NPC before its recruitment mission can disturb story assumptions. The author's documentation lists recruitable Heartland-character support, but that does not establish this whole setup's story compatibility. The menu and recruitment flow still need runtime confirmation.

## Influence and loot

The custom recipe doubles positive activity-currency fields in four current reward assets. Heartland explicitly references the default table. Mission-specific payouts and trade prices are unchanged; the patch does not create unlimited currency or alter character standing values.

Map quotas are original game values. Removing the previous 2x preset changes future map generation, not loot already stored in a save. Heartland is not reset automatically. Daybreak has its own scripted supplies and reward systems; Campaign/Heartland map quotas do not multiply its crates.
